# [Check Triplet With 0 Sum](https://www.geeksforgeeks.org/problems/find-triplets-with-zero-sum/1)
## Medium
Given an array&nbsp;arr[] of integers, find if it contains a triplet whose sum equals zero.Examples:Input: arr[] = [0, -1, 2, -3, 1]Output: true
Explanation: The triplet [0, -1, 1] has a sum equal to zero.Input: arr[] = [1, 2, 3]Output: false
Explanation: No triplet with a sum of zero exists.Input: arr[] = [-5, 3, 2, -1, 0, 1]Output: true
Explanation: The triplet [-5, 3, 2] has a sum equal to zero.
